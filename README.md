# Spam Detection System

## Overview

Spam Detection System is a web application developed using Django and Machine Learning to classify messages as Spam or Ham (Not Spam). 
The system uses a trained machine learning model to analyze user-input text and predict whether it is spam.

## Features

* Detects spam messages in real time
* Machine Learning based prediction
* Django web framework
* User-friendly interface
* SQLite database support

## Technologies Used

* Python
* Django
* Pandas
* NumPy
* HTML/CSS

## Project Structure

* `backend/` - Django backend and machine learning model
* `frontend/` - User interface
* `manage.py` - Django project manager
* `db.sqlite3` - Database file
